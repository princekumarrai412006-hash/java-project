# StudyHub Project Statement

## Problem statement
Students often track courses, assignments, deadlines, and study effort in disconnected notes. This makes it difficult to see overdue work, measure progress, and plan time across subjects. StudyHub provides a small, reliable Java application that centralizes course and task records and produces an understandable workload summary.

## Scope
The project covers course creation, task planning, task completion, relational persistence, validation, progress analytics, and a console workflow. It does not include multi-user authentication, a web UI, notifications, or cloud deployment; those are future enhancements.

## Target users
The primary users are undergraduate students studying Java and database programming. A teacher or evaluator can also use the project to inspect examples of Java OOP, JDBC, JPA, collections, exception handling, and multithreading.

## High-level features
- Course and assignment records with due dates and estimated minutes.
- JDBC CRUD repository backed by H2.
- JPA entities, relationships, and JPQL query demonstration.
- Completion tracking and concurrent workload analytics.
- Input validation, custom exceptions, prepared statements, and unit tests.
- Architecture, UML, workflow, ER, and implementation documentation.
